# MaiMLStandaloneViewer

MaiML (Measurement Analysis Instrument Markup Language) ファイルを可視化・分析するためのスタンドアロン Webアプリケーション。

## 🌟 主な機能

### 📊 グラフ可視化
- **Petri Net ベースのワークフロー可視化**：実験プロセスの状態遷移をノードグラフで表示
  - **Place（円）**：試料やデータの状態を表現
  - **Transition（長方形）**：処理やイベントを表現
- **参照関係の可視化**：（キャンバス左上の 🔗 Link パネルで種類ごとに表示On/Off可）
  - **Template Ref（黄色の破線）**：テンプレート同士の参照関係
  - **Instance Ref（緑色の破線）**：インスタンス同士の参照関係
  - **Chain Link（橙色の破線）**：異なるMaiMLファイル間の連鎖（`<chain>`）関係。ハッシュ値による整合性検証も表示
  - **Parent Link（紫色の破線）**：改訂元ファイルとの連鎖（`<parent>`）関係の可視化
  - **Same UUID: Template（青紫の破線）**：同一UUIDを持つTemplateノード同士の対応関係
  - **Same UUID: Instance（薄紫の破線）**：同一UUIDを持つInstanceノード同士の対応関係

### 📄 メタデータ管理と表示
- **ドキュメント情報パネル**：作成者、UUID、説明、ベンダー情報の一元表示
- **詳細パネル**：選択ノードの関連テンプレート・インスタンス情報を表示
- **テンプレート・インスタンスの階層表示**：ノード選択で該当データを自動抽出

### 📁 ファイル対応
- **.maiml ファイル対応**：MaiML 標準フォーマットを完全サポート
- **.zip アーカイブ対応**：ZIP内のMaiMLファイルと関連画像/データを自動リンク
- **埋め込みファイルプレビュー**：表示形式を 🖼️ Image / 📊 Chart / 📋 Table / 📝 Text / 📈 EMSA Spectrum から選択
  - 画像（JPG, PNG, TIFF等）の直接表示
  - CSV/テキストデータのテーブル表示
  - TIFF マルチページ対応
  - EMSA/MAS スペクトル形式の表示

### 🎨 UI/UX 機能
- **ライト/ダークテーマ対応**：CSS変数によるシームレスな切り替え
- **レスポンシブデザイン**：水平・垂直リサイザーでパネルサイズを調整
- **キャンバス・ツールバー**：グラフエリア左上の 🔗 Link / ⚙ View / 📷 Image の3パネル（同時に開くのは1つ。設定はブラウザに保存され次回起動時に復元）
- **グラフ操作**：
  - マウスホイールによるズーム（0.25 ～ 6倍）
  - ドラッグによるパン移動
  - ノード手動配置（⚙ View パネルの Drag Edit）

### 🎯 レイアウト機能
- **Force-directed Layout**（✧ Auto）：力学モデルによる自動配置
- **Dagre Hierarchical Layout**（⌗ Dagre）：階層的な自動整理
- **配置リセット**（⟲ Reset）
- **グリッド表示/スナップ**：⚙ View パネルの Show Grid / Snap to Grid。グリッド間隔は 10〜100px で変更可

### 📷 ペトリネット図の画像出力
キャンバス左上の **📷 Image** パネルから、表示中のペトリネット図を画像として出力できます。**現在のズーム/パン位置に関わらず、常にグラフ全体が収まる範囲**で出力されます。

- **Copy to Clipboard**：PNG画像としてクリップボードにコピー（Word / PowerPoint にそのまま貼り付け可）
- **Save as PNG**：PNG画像としてファイル保存
- **Save as SVG (vector)**：ベクター形式で保存。拡大しても劣化しないため論文・資料の図版に適する
- **オプション**：
  - **Scale**：PNGの出力倍率（1x〜4x、既定 2x）
  - **Background**：`Theme`（現在のテーマ色・既定）/ `White` / `Transparent`
  - **Include grid**：グリッド線を画像に含める
- ℹ️ クリップボードへのコピーは Chrome / Edge で動作します。非対応・失敗時は自動的にPNGファイル保存に切り替わります
- ℹ️ ダークテーマでは文字が白いため、`Transparent` を選ぶと白い資料に貼ったときに文字が見えなくなります
- ℹ️ 画像内のフォントは環境標準のフォントに置き換えられるため、画面表示とわずかに異なる場合があります

### 🤖 AI 分析機能
- **クラウド / ローカル LLM 切替対応**：詳細データの AI 要約
  - **☁️ Cloud (Gemini)**：Google Gemini API統合。高精度・高速だがデータはGoogleサーバーに送信される
  - **🖥️ Local (Ollama)**：ローカルLLM（Ollama）を使用。データを外部送信せずに要約可能（要 Ollama インストール）
- **複数プロンプトテンプレート**：
  - Quick Summary
  - Standard Summary
  - Detailed Report
  - Custom Prompt（ユーザー定義）
- **マークダウン形式で結果表示**：保存・コピー機能完備

### 📊 データプロット機能
- **3種類のグラフ形式**：
  - **Line（折れ線）**：時系列トレンド表示
  - **Bar（棒グラフ）**：ヒストグラム表示
  - **Scatter（散布）**：相関分析表示
- **インタラクティブ操作**：ズーム、パン、リセット機能
- Chart.js + チャートズームプラグイン統合

### 📈 メタデータエクスポート
複数形式でのデータ出力対応：
- **Excel (.xlsx)**：シート構成による一覧表示
- **JSON (.json)**：階層構造を維持した生データ
- **CSV (.csv)**：汎用ツール連携用

### 🔐 XML 暗号化データ対応（JIS K0200 準拠）
- **AES-256-GCM + PBKDF2-SHA256 復号対応**：W3C XML Encryption 1.1 準拠
- **暗号化バナー通知**：検出時に自動表示
- **一括復号機能**：「Decrypt All」ボタンで全要素を一度に復号
- **個別復号オプション**：ノードごとの段階的復号
- **パスワードキャッシング**：セッション中の自動再利用
- ⚠️ **制限**：パスワード方式のみ対応（RSA/鍵ラップ方式は未対応）

### 🛢️ Data Lake（ローカルフォルダ一括管理）
- **フォルダ接続**：ローカルフォルダをまるごと接続し、フォルダ内の `.maiml` / `.maiml.zip` ファイルをサブフォルダも含めて再帰的にスキャン・一覧化
- **検索の二層構成**：
  - **索引**（絞り込み専用）— ファイル名・相対パス・日付・instrument・creator・vendor・owner・UUID を保持
  - **本文の直接走査** — property の key / value、description など任意のキーワードを対象。索引に無い語もヒットする
- **フィルタ**：測定日時の期間（From / To）、Instrument / Creator / Vendor / Owner のチェックボックス。キーワードとは AND 条件
- **並び替え**：日付（新しい順/古い順）、ファイル名、ファイルサイズで並び替え
- **一括読み込み**：絞り込んだファイルを選択し、複数ファイルをまとめてビューアに読み込み
- **セッション間キャッシュ**：フォルダのインデックスを `localStorage` にキャッシュし、次回起動時に即時復元。「Sync / Re-Verify」で再スキャン・再接続
- ℹ️ **対応ブラウザ**：Chrome / Edge（File System Access API使用）。Firefox / Safari はフォールバック動作となり一部機能が制限される
- フォルダへのアクセスは読み取り専用（ファイルの変更・削除は行わない）
- ⚠️ **小規模向けの簡易検索**です。以下の割り切りがあります
  - 走査対象の合計が 200MB を超える場合は自動実行せず、警告とボタンを表示
  - ZIP は展開のため丸ごとメモリに載せるため、64MB を超えるものは対象外
  - 走査結果はキャッシュしないため、キーワードを変えるたびに読み直し
  - 索引作成（フォルダを開いた初回）は本文走査に比べて重く、数百ファイルでは数分規模

### 🔏 XML署名検証機能（ds:Signature）
- **署名整合性の自動検証**：W3C XML Signature 準拠で署名されたMaiMLファイルを読み込むと、署名後に改変されていないかを自動検証
- **アルゴリズムを固定しない検証**：`ds:SignatureMethod` に従って自動選択するため、**RSA-SHA256 / ECDSA-SHA256 のいずれも検証可能**（MaiML Studio が出力するのは RSA-SHA256）
- **検証結果バッジ**：右上パネル（Document Metadata）の最上部に表示
  - 🔏 **Verifying...** — ファイル読み込み中の検証処理中
  - ✅ **Integrity OK** — 署名・ハッシュがファイル内容と整合。署名アルゴリズム名と、公開鍵のフィンガープリント（先頭4バイト）を併記
  - ❌ **Integrity check failed** — ハッシュまたは署名値の不一致を検出
  - ⚠️ **Unsupported signature format** — このビューアが解釈できない形式の署名（例：旧 MaiML Studio が出力した `dsig11:ECKeyValue` 形式の鍵情報）。**ファイル自体は壊れていない可能性があり、改ざんとは区別して扱われます**
- **鍵フィンガープリント**：`ds:KeyInfo` の鍵素材の SHA-256 先頭4バイト。鍵の書式に依存しないため、「同じ鍵で署名された複数のファイル」を目視で照合できます
- ⚠️ **注意**：この検証は「署名後に改変されていないか」の整合性チェックであり、署名者の真正性（誰が署名したか）までは証明しない（公開鍵がファイル自体に同梱されるため）

## 🚀 使用方法

### インストール・実行
1. `MaiMLStandaloneViewer.html` をダウンロード
2. ブラウザで直接開く（サーバー不要）
3. または任意のWebサーバーで配信

### 基本操作

#### ファイル読み込み
画面左上の **📂Upload Files…** ボタン、または画面へのドラッグ＆ドロップでファイルを読み込みます。

- **対応形式**：`.maiml` およびこれらを含む `.zip` ファイル
- **ZIP対応**：ZIPファイルをアップロードすると、内部のMaiMLファイルと画像/データファイルを自動的に紐付けて展開
- ローカルフォルダをまとめて管理したい場合は、Chrome / Edge限定で **🛢️ Data Lake** 機能も利用可能（詳細は上記「Data Lake」参照）

#### グラフ操作

| 操作 | 方法 |
|------|------|
| 移動（Pan） | 何もないところをドラッグ |
| 拡大縮小（Zoom） | マウスホイール（0.25 〜 6倍） |
| ノード移動 | 各ノード（丸や四角）をドラッグ（⚙ View パネルの **Drag Edit** で有効/無効を切替） |
| レイアウト自動調整 | ヘッダーの **✧ Auto**（力学モデル）または **⌗ Dagre**（階層型）ボタン |
| 配置リセット | ヘッダーの **⟲ Reset** ボタン |
| グリッド表示/スナップ | ⚙ View パネルの **Show Grid** / **Snap to Grid**（間隔は ＋/− で 10〜100px） |
| 関係線の表示切替 | 🔗 Link パネルの6種類のチェックボックス（templateRef / instanceRef / chain / parent / same uuid:Template / same uuid:Instance） |
| 図の画像出力 | 📷 Image パネル（詳細は上記「ペトリネット図の画像出力」参照） |
| ライト/ダーク切替 | ヘッダーの **🌙 Theme** ボタン |

> 🔗 Link パネルのラベル横のドットは、**点灯（緑の●）なら全ての関係線が表示中**、**消灯（中空の○）なら非表示にしている関係線がある**ことを示します。パネルを折り畳んでいても分かるため、「線を隠したまま忘れて、その関係が存在しないと誤読する」ことを防げます。ドットにマウスを乗せると隠している種類の数が表示されます。
